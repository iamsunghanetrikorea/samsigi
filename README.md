# 건강한 세 끼 — 60세 이상 맞춤형 식단 관리 웹앱

`samsigi_PRD.md` 기반으로 구현한 모바일 우선 PWA입니다. 서버 없이 브라우저에서만 동작하며, 개인 데이터는 기기(IndexedDB)에만 저장됩니다.

## 주요 기능

| 화면 | 기능 (PRD 요구사항) |
|---|---|
| 시작하기 | 회원가입 없이 프로필 입력 → 이번 주 21끼 자동 생성 |
| 홈 | 오늘의 세 끼, 영양 달성률, 먹었어요 체크, 간식·음료 기록 |
| 식단 > 주간 | 7일×3끼, 한 끼 바꾸기(FR-03), 고정·매주 고정(FR-09), 하루/주 재생성(FR-04), 지난주 복사, 외식 표시(FR-10), 인쇄·CSV |
| 식단 > 월간 | 실제 일수(28~31일) 달력, 날짜별 미리보기·상세, 빈 날 채우기/전체 재생성(FR-02) |
| 레시피 모음 | 한식·중식·양식·간식·찌개·국 분류 필터, **업데이트** 버튼으로 추천 메뉴 묶음(36종)에서 분류별 새 메뉴 추가 |
| 레시피 | 1~4인분 재료량 자동 조정, 대체 재료(영양 재계산), 단계별 조리법, 음성 읽기, 조리 타이머, 없는 재료만 장보기 담기 |
| 장보기 | 기간별 재료 합산, 보유량 차감, 보관기간 고려 분할 장보기, 단가 수정·예상 식비, 체크리스트, 인쇄·CSV, 남은 재료 활용 메뉴 |
| 식당 | 현재 위치(권한 거부 시 주소 입력) 주변 식당 검색, 분류·거리 필터, 네이버·카카오·구글 지도 링크, 외식 기록, 단골 식당 저장(혼밥·예산 필터) |
| 통계 | 주별/월별 평균 열량·탄단지·나트륨, 일별 열량 막대, 먹은 비율·외식·재료비 |
| 설정 | 프로필·식이 제한·영양 목표 직접 수정, 글자 크기(18~26px)·고대비, JSON 백업/복원, 전체 삭제 |

### 식단 추천 엔진 (`src/lib/planner.js`)
1. 알레르기·제외 재료·난이도·조리시간·씹기 조건으로 후보 필터
2. 후보별 영양 계산 — 끼니 목표 열량에 맞춰 밥·면 양을 0.6~1.5배 자동 조절
3. 점수: 열량·단백질·나트륨·탄수화물·지방 편차, 3일 내 같은 주메뉴 반복, 식비 초과, 제철 재료, 보유·최근 재료 재활용, 즐겨찾기·선호
4. 하루 3끼 조합 최적화(상위 6×6×6) 후 순차적으로 기간 생성
5. 조건을 충족할 수 없으면 부족 영양소·충돌 조건을 안내

### 영양 계산
- 유지 열량: Mifflin–St Jeor 기초대사량 × 활동계수 (직접 입력 가능)
- 탄수화물·단백질 4kcal/g, 지방 9kcal/g 교차 검증 표시
- 간식·음료 열량은 세 끼와 별도 관리
- 모든 수치는 **추정치**로 표시 — 출처는 `docs/DATA_SOURCES.md`
- 음식 사진 32장은 Wikimedia Commons 자유 이용 사진(예시 사진) — 출처·라이선스는 `docs/PHOTO_CREDITS.md`, 레시피 화면에도 표기

## 실행

```bash
npm install
npm run dev        # 개발 서버 http://localhost:5173
npm test           # 엔진 테스트 (PRD 13장 검수 기준)
npm run build      # dist/ 에 정적 파일 생성
npm run preview    # 빌드 결과 미리보기 (서비스 워커 포함)
```

## 배포

- **GitHub Pages**: 저장소에 푸시 → Settings > Pages > Source를 "GitHub Actions"로 지정. `.github/workflows/deploy.yml`이 테스트·빌드·배포를 수행합니다.
- **Cloudflare Pages**: 빌드 명령 `npm run build`, 출력 디렉터리 `dist`.
- **수동**: `dist/` 폴더(또는 `samsigi-dist.zip`)를 아무 정적 호스팅에 올리면 됩니다. `base: './'`와 해시 라우팅을 써서 하위 경로에서도 동작합니다.

## 사용자 안내 (설치·관리)

- **홈 화면에 설치**: 휴대폰 브라우저 메뉴 → "홈 화면에 추가". 이후 인터넷 없이도 식단·레시피를 볼 수 있습니다.
- **글자 크기**: 더보기 → 설정 → 화면에서 5단계 조절, 고대비 모드 지원.
- **백업**: 설정 → "백업 파일 내보내기"로 JSON 저장, 새 기기에서 "백업 불러오기".
- **삭제**: 설정 → "모든 데이터 삭제" (되돌릴 수 없음).
- **인쇄·PDF**: 식단·장보기·레시피 화면의 "인쇄·PDF" → 인쇄 대화상자에서 "PDF로 저장".

## 개인정보·보안
- 프로필·건강정보는 기기에만 저장되며 외부 전송이 없습니다. 건강 상태 입력은 별도 동의 후 활성화됩니다.
- 식당 검색만 외부(OpenStreetMap Overpass·Nominatim)로 좌표/주소를 보내며, 첫 사용 시 동의를 받습니다. 비밀 API 키를 쓰지 않습니다.
- 네이버·카카오 지도는 검색 링크로만 연결합니다. 공식 지도 SDK를 붙이려면 키를 서버리스 프록시 뒤에 두세요.

## 주의
이 서비스는 일상 식단 계획을 지원하며 진단·치료·의료적 영양처방을 대체하지 않습니다. 신장질환, 당뇨병, 연하곤란 등은 전문가 상담을 안내합니다.
