# 레시피·영양 데이터 출처

- 갱신일: 2026-11-14
- 파일: `src/data/ingredients.js`(식재료 영양), `src/data/recipes.js`(레시피)

## 영양 수치
식재료 100g(가식부, mL는 100mL)당 열량·탄수화물·단백질·지방·나트륨은 아래 공개 자료의 **대표값을 참고해 반올림한 추정치**입니다.

- 농촌진흥청 국립농업과학원, 「국가표준식품성분표」 제10개정 — https://koreanfood.rda.go.kr
- 식품의약품안전처, 식품영양성분 데이터베이스 — https://various.foodsafetykorea.go.kr/nutrient

> ⚠️ 현재 값은 원자료 행 단위로 대조하지 않은 근사값입니다. 실제 서비스 전에 각 식재료를 위 DB의 해당 식품코드와 대조해 `ingredients.js`의 값을 교체하고, 식품코드를 함께 기록하는 것을 권장합니다.

조리 후 기준 식재료(밥, 삶은 면, 삶은 콩)는 장보기 시 `buyAs.ratio`로 구매 형태(쌀·건면 등)로 환산합니다. 멸치육수는 육수 1L당 멸치 약 20g으로 환산합니다.

## 단가
`price`(원/100g, 구매 형태 기준)는 2026년 국내 대형마트·전통시장 시세를 대략 반영한 예시값입니다. 앱의 장보기 화면에서 사용자가 품목별 단가를 직접 고칠 수 있습니다.

## 레시피
36종 모두 이 앱용으로 작성한 가정식 구성이며 1인분 기준 재료량입니다. 조리 시간은 가정용 화구 기준 근사값입니다.

## 업데이트 추천 메뉴 (src/data/recipePack.js)
한식·중식·양식·간식·찌개·국 각 6종, 총 36종입니다. 널리 쓰이는 가정식 조리법을 바탕으로 60세 이상에 맞게 간(나트륨)을 줄이고 단계를 단순화해 작성했으며, 특정 출처의 레시피를 옮긴 것이 아닙니다. 각 레시피 화면에 유튜브·만개의레시피 검색 링크를 참고 자료로 제공합니다. 영양값은 위 식재료 DB로 계산한 추정치입니다.

## 외식 열량
식당 메뉴는 공식 영양정보가 거의 없으므로 분류별 추정값(백반 약 700kcal 등)만 쓰며, 앱에서 "추정치"로 표시합니다. 사용자가 비워 두면 합계에서 제외합니다.

## 식당 정보
OpenStreetMap 기여자 자료(ODbL)를 Overpass API로 조회합니다. 영업정보는 실제와 다를 수 있어 지도 앱에서 다시 확인하도록 안내합니다.
